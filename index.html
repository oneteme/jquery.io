Et si l'accès à vos données devenait plus simple ?

Vos applications évoluent. Vos besoins augmentent, vos données se multiplient et les demandes se diversifient. Vous devez alors :

  • Rechercher une informations
  • Filtrer et/ou grouper des données
  • Calculer des indicateurs

À mesure que ces besoins augmentent, leur mise en œuvre devient plus complexe.

Pourquoi consacrer autant d'efforts à la manière d'obtenir les données, lorsque vous savez déjà ce que vous souhaitez obtenir ?

Moins de complexité. Plus de temps pour l'essentiel.

Testez en Live
select=cat_id&price.avg.gt(10)&rankProducts=1
JQuery 
WITH g1 AS (
    SELECT
      *,
      RANK() OVER (
        PARTITION BY
          s_v1.CATEGORY_ID
        ORDER BY
          s_v1.PRICE DESC
      ) AS "OVER_429238734"
    FROM
      PRODUCTS_TABLE s_v1
  )
SELECT
  g1.CATEGORY_ID AS "catId"
FROM
  g1
WHERE
  g1."OVER_429238734" = 1
GROUP BY
  "catId"
HAVING
  AVG(g1.PRICE) > 10.0

Important : JQuery n'est pas jQuery

jQuery

Une bibliothèque JavaScript, utilisée principalement pour le développement web.

JQuery

Un framework Java pour travailler avec les requêtes de base de données.

Les deux projets n'ont strictement aucun lien.

Une bibliothèque, pas un ORM

JQuery est une bibliothèque dédiée à l'accès aux données. Elle permet de construire et d'exécuter les requêtes nécessaires pour obtenir les informations recherchées.

JQuery — bibliothèque

  • Vous décrivez ce que vous souhaitez obtenir, JQuery construit la requête nécessaire.
  • Les résultats correspondent directement aux données recherchées.
  • JQuery se concentre sur l'accès aux données.
  • Il s'intègre à votre environnement existant sans remplacer votre architecture.

ORM

  • Vous définissez des entités représentant les données.
  • L'ORM transforme les données en objets.
  • Il gère notamment les relations entre les entités.
  • Il ajoute une couche d'abstraction entre l'application et la base de données.

Un ORM gère vos objets, JQuery facilite l'accès à vos données.

Les points forts de JQuery

Gain de temps

Une même API peut répondre à différents besoins : sélectionner, filtrer, trier ou transformer les données selon la demande.

Moins de développements, plus de temps pour répondre aux besoins.

Une seule API 3 demandes différentes
/customers?select=name,country
Afficher le nom et le pays de tous les clients
/customers?select=name,city&country=France
Afficher le nom et la ville des clients d'origine française
/customers?select=count,country
Afficher le nombre de clients par pays
… et autant d'autres demandes que nécessaire, sans nouvelle API.

Accessibilité

Comprendre les principales notions liées à la manipulation des données suffit pour accéder simplement aux données recherchées.

La complexité nécessaire pour les obtenir est ensuite prise en charge par JQuery.

En résumé

JQuery simplifie l'accès aux données en vous permettant de vous concentrer sur ce que vous souhaitez obtenir.

  • Gagner du temps en réduisant les développements nécessaires
  • Accéder plus simplement aux données
  • Filtrer, transformer et calculer les données
  • Regrouper et comparer les résultats
  • Utiliser les jointures et les opérations avancées
  • Travailler avec différentes bases de données

Vous décrivez ce que vous voulez. JQuery s'occupe de la requête.
